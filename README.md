# Предсказание возраста посетителей сайтов

Учебный проект: многоклассовая классификация возрастной категории пользователя по его цифровому следу (посещения сайтов, активность с рекламой, устройство и др.) для таргетирования рекламы.

> **Яндекс Практикум, программа «Data Science», модуль 3** — проект «Предсказание возраста посетителей сайтов».

## Результаты

| Модель | F1 (macro), CV | F1 (macro), train | F1 (macro), test |
|---|---|---|---|
| DummyClassifier (baseline) | 0.215 | 0.200 | — |
| LogisticRegression (по умолчанию + RFE) | 0.713 | 0.729 | — |
| SVC (по умолчанию + RFE) | 0.717 | 0.723 | — |
| **LogisticRegression (после подбора)** | **0.7815** | 0.796 | **0.772** |

Целевой порог по заданию — F1 ≥ 0.75. На тесте: accuracy 0.81, F1 по классам 0.58–0.88; хуже всего предсказывается класс «18–25 лет» (F1 0.58).

## Данные

Шесть CSV-файлов (загружаются по ссылке `https://code.s3.yandex.net/datasets/`, локальная копия не нужна):

| Файл | Содержание |
|---|---|
| `ds_s13_users.csv` | `user_id`, `age_category` (0: <18, 1: 18–25, 2: 26–40, 3: 41–55, 4: 56+) — целевая переменная |
| `ds_s13_visits.csv` | логи посещений: дата, время суток, сессия, категория сайта |
| `ads_activity.csv` | активность взаимодействия с рекламой (CTR-категория) |
| `surf_depth.csv` | глубина просмотра за сессию |
| `primary_device.csv` | основное устройство |
| `cloud_usage.csv` | использование облачных сервисов |

Итог: 5 826 пользователей (по одной строке на пользователя), 38 признаков. Удалены дубликаты: 87 в users, 233 в ads_activity, 15 750 полных дубликатов в visits.

## Метод

1. EDA по каждой таблице, удаление дубликатов.
2. Агрегация логов посещений до уровня пользователя: доли посещений по категориям сайтов и времени суток, число сессий и т. п.
3. Объединение таблиц по `user_id` (left join), phik-корреляции с целевой переменной.
4. Разбиение train/test 80/20 со стратификацией (`random_state=42`).
5. `Pipeline`/`ColumnTransformer`: импутация, `StandardScaler`, `OneHotEncoder`.
6. Отбор признаков: фильтрация по корреляциям и RFE (25 признаков).
7. Сравнение DummyClassifier, LogisticRegression и SVC на StratifiedKFold (5 фолдов), метрика F1 с macro-усреднением.
8. GridSearchCV для LogisticRegression (лучшая: `C=0.1`, `class_weight='balanced'`) и SVC.
9. Финальная оценка на тесте, сохранение артефактов через `joblib`.

## Ограничения

- RFE обучен на всей обучающей выборке до кросс-валидации, поэтому CV-оценка (0.7815) слегка оптимистична; ориентироваться стоит на тест (0.772).
- Класс 18–25 лет предсказывается заметно хуже остальных.
- Данные учебные, аналогичной проверки на реальном трафике не проводилось.
